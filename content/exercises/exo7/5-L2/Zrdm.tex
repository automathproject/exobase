\question{
Donner les deux premiers termes du DL pour $n\to\infty$ de
$I_n =  \int_{t=0}^1 \frac{d t}{1+t^n}$.
}
\reponse{
$1-\frac{\ln 2}n +  o\Bigl(\frac1n\Bigr)$.
}
