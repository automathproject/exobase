\begin{question}
\qclassification{225.01}
\qtags{motcle=équations homogènes/solution générale}
On considère les équations différentielles :
$$(E_1)\; :\; y'-2y=0\quad \mbox{ et }\quad (E_2)\; :\; y'+2xy=0.$$
Parmi les affirmations suivantes cocher celles qui sont vraies :
\begin{answers}
\bad{La solution générale de $(E_1)$ sur $\Rr$ est : $\displaystyle y=k\mathrm{e}^{-2x}$, $k\in \Rr$.}
\good{La solution générale de $(E_1)$ sur $\Rr$ est : $\displaystyle y=k\mathrm{e}^{2x}$, $k\in \Rr$.}
\good{La solution générale de $(E_2)$ sur $\Rr$ est : $\displaystyle y=k\mathrm{e}^{-x^2}$, $k\in \Rr$.}
\bad{La solution générale de $(E_2)$ sur $\Rr$ est : $\displaystyle y=k\mathrm{e}^{x^2}$, $k\in \Rr$.}
\end{answers}
\begin{explanations}
Une primitive de $-2$ est $-2x$, donc la solution générale de $(E_1)$ sur $\Rr$ est :
$$y=k\mathrm{e}^{2x},\quad k\in \Rr.$$
Une primitive de $2x$ est $x^2$, donc la solution générale de $(E_2)$ sur $\Rr$ est :
$$y=k\mathrm{e}^{-x^2},\quad k\in \Rr.$$
\end{explanations}
\end{question}
