Sources brutes ou importées avant normalisation.

- `raw/` conserve les dépôts, archives ou extractions d'origine.
- `staged/` contient les sources préparées avant conversion.
- `manifests/` décrit les lots importés, leur provenance et les règles appliquées.

Note : les imports initiaux (amscc, crouzet, exo7) ont été réalisés avant que cette
structure soit en place. Leur provenance est documentée dans `content/provenance/`.
Ces dossiers sont destinés aux imports futurs.
